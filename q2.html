How the Action attribute works

... in my own words

The action attribute of a form tag specifies where to send data. For example, when a user is done filling out a form, as soon as they submit this information, the action attribute holds an address to which the data is then sent (e.g. an endpoint). This is great for collecting lots of data from many users; more specifically, this is a good way to collect unmoderated quantitative testing data. Because you decide where the data goes, you can send it to a place that sorts or summarizes it. Or, with a contact form, the data might be sent to a queue that periodically emails the intended recipient. There are many uses, and it carries significant responsibility for what happens to the information being collected.
