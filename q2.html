How the Action attribute works

... in my own words

The responsibility of the action attribute of a form tag is to send data to the proper destination. For example, when a user is done filling out a form, as soon as they submit this information the action attribute holds an address which is where the data is then sent to. This is great for collecting lots of data from many users, more specifically this is a good way to collect unmoderated quantitative testing data. Beacuse you get to decide where the data goes you can send it to a place that sorts this information or even summarizes it.
